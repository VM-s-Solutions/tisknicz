# Makables — frontend

Next.js 16 (App Router), React 19, Tailwind 4. **Pure presentation layer.**

Every piece of truth comes from the .NET backend over the NSwag-generated client. Nothing here decides anything.

## Layout

```
src/
├── app/
│   ├── page.tsx      # landing
│   ├── (public)/     # katalog + maker detail, produkt detail, jak-to-funguje, pro-makery, kontakt, vop, gdpr
│   ├── (auth)/       # login, register, magic link, reset, verify
│   ├── (customer)/   # objednavka (checkout + detail), dashboard/zakaznik (objednavky, profile)
│   ├── (maker)/      # dashboard/maker — objednavky, produkty, recenze, vyplaty, profil
│   └── (admin)/      # dashboard/admin — makers, orders, faktury, vyplaty, kategorie, users, countries, outbox, audit
├── components/       # ui/ primitives + feature components
├── lib/
│   ├── api-client/   # GENERATED by NSwag — customer / maker / admin / public
│   ├── runtime/      # apiFetch → Result<T, ApiError>, auth state, SSR cookie forwarding
│   ├── i18n/         # cs-CZ catalog — every user-facing string
│   ├── money/ format/ validation/ seo/ routing/ catalog/ orders/ consent/
│   └── testing/      # test helpers
└── middleware.ts     # route protection
```

## Rules that are enforced, not suggested

- **Server Components by default.** `'use client'` only for real interactivity, pushed as far down the tree as possible.
- **No data fetching in `useEffect`.** Server Components fetch on render; Client Components call the API client from event handlers.
- **No business logic** — no pricing math, no validation rules, no state machines.
- **No database SDK.** The only data path is `lib/api-client/` through [`lib/runtime/api-fetch.ts`](./src/lib/runtime/api-fetch.ts). Multipart uploads must pass an explicit long `timeoutMs` — the 8 s default aborts them.
- **`lib/api-client/` is generated, never hand-edited.** A pre-commit hook blocks edits; CI checks spec parity.
- **No global state libraries.** Server state lives on the server; UI state is local; the URL is the state container for filters and pagination.
- **All user-facing strings from `lib/i18n/cs-CZ`.** Every `BusinessErrorMessage` code the backend can return has a parallel Czech key.
- **Responsive at 375 / 768 / 1280**, verified in Chrome *and* WebKit — both have bitten us.

## Local development

```bash
npm install
npm run dev          # http://localhost:3000
```

The backend hosts must be running (`pwsh ../scripts/run-dev.ps1`) — the app defaults to ports 5001 / 5002 / 5003 / 5104, so no `NEXT_PUBLIC_API_*_BASE_URL` is needed locally. If pages show **"Server je momentálně nedostupný"**, a host is down. Note that `next.config.ts` is read once at startup: restart `next dev` after changing it.

```bash
npm run test         # vitest + Testing Library + jest-axe
npm run lint
npm run generate:api # regenerate the client from the running hosts
npm run check:api    # spec parity (ADR 0022) — same check CI runs
```
