# Test plan — T-0140 (maker fee-rate override)

## Scope under test
`Maker.FeeRateOverrideBp` / `Maker.SetFeeRateOverride`; the
`SetMakerFeeOverride` admin command (Web.Admin `POST
/api/v1/makers/{makerId}/fee-override`); `PricingService`'s
`maker.FeeRateOverrideBp ?? config.PlatformFeeRateBp` resolution branch;
`OrderPricing.Compute`'s caller-resolved `platformFeeRateBp` parameter.
Purely a backend + data-contract ticket — no frontend UI or i18n in this
pass (explicit follow-up, per PM instruction).

## Preconditions
- `AddMakerFeeRateOverride` EF Core migration applied.
- A CZ `CountryConfiguration` row with `PlatformFeeRateBp = 700` (already
  seeded by the prior `UpdateCzPlatformFeeRate` data-fix migration).
- A verified `Maker` + `Product` (Fixed price) for order-creation flows.
