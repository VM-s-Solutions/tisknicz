# Test plan — T-0084a (stub — filled before bundle PR review)

> 2026-06-10 fold: TC-2 route corrected (review N-3); TC-13 boundary made precise and
> TC-16–TC-22 added per the Gate 9 + QA audit fold list (F1–F3, F5).

## Scope under test
Checkout order form at `/objednavka?productId=…`: entry guards, contact-field
validation mirrors, shipping-method gating (Packeta widget + personal pickup),
attachment pre-checks, submit orchestration (create → sequential uploads →
navigate to `/objednavka/<orderId>` with `?attachmentsFailed=<n>` on partial
failures).

## Preconditions
- Vercel preview against the staging backend.
- Confirmed customer account; an unconfirmed account for the 403 case.
- Active fixed-price product; an `OnRequest` product; an inactive product id.
- Maker WITH personal pickup enabled and maker WITHOUT it.
- Packeta public widget key configured on staging (T-0070 manual step
  `packeta-public-widget-key-secret`) — pre-condition, QA blocked without it.
- Test files of an allowed type: exactly 10 MiB (10 485 760 B), 10 MiB + 1 B
  (10 485 761 B), and a `.zip`.
- DevTools network throttling available (custom profile, ~1 Mbps uplink).
- Admin/staging access to toggle maker `IsVerified` and personal-pickup
  settings mid-session (for TC-19/TC-20).
