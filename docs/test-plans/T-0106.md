# Test plan — T-0106 (open + resolve dispute)

## Scope under test
Dispute parenthesis state: party open endpoints
(`POST /api/v1/customer/orders/{id}/dispute`,
`POST /api/v1/maker/orders/{id}/dispute`), admin open + resolve
(`POST /api/v1/admin/orders/{id}/dispute`, `.../dispute/resolve`),
carrier-sourced open via the rewired `DisputeShipment` inside
`SyncShipmentStatusesFunction`, `PreDisputeState` restore semantics,
nested `RefundOrder.Command` dispatch on the Refunded outcome,
admin-notification + dispute-resolved emails, sweep exclusion, and the
message-thread evidence channel.

Party/admin endpoints have no UI yet (T-0118) — manual cases execute via
Swagger/curl with the matching audience JWT per host.

## Preconditions
- Staging backend from the bundle branch; `disputes` table + partial
  unique index + `orders.pre_dispute_state` migration applied; dispute
  email template seeds present.
- **Admin account** (admin JWT) + customer account owning seeded orders
  + the matching maker account + an unrelated second customer (for the
  cross-tenant probe).
- **`ADMIN_NOTIFICATION_EMAIL` set on staging** (T-0106 manual step) and
  its mailbox accessible. One test run (TC-12) deliberately UNSETS it —
  schedule that last and restore afterwards.
- Seeded orders: one each in Paid, Accepted, Shipped (Zásilkovna, with
  `AutoDeliverAt` in the past for TC-10), Delivered, plus Completed /
  Cancelled / Refunded / PendingPayment for the blocked theory.
- T-0105 executed first on the same environment (resolve-Refunded
  dispatches RefundOrder; Comgate sandbox reachable).

## Edge cases
- Party submits `category: CarrierReturned`/`CarrierFailed` → 400
  `order.dispute.categoryNotAllowed` (carrier-reserved, §C.6) — customer
  AND maker endpoints.
- Description exactly 2000 chars accepted / 2001 rejected; leading and
  trailing whitespace trimmed in the stored row.
- Resolve on an order whose `pre_dispute_state` is NULL in the DB
  (hand-crafted row): must fail loudly with a logged Critical, never
  NullReference (reviewer HIGH-5 — no bare `!`).
- Resume after the auto-deliver window elapsed during the dispute: next
  sweep auto-delivers immediately — accepted per §C.10, verify it does
  not double-fire emails.
