# T-0118a — Manual QA plan (admin shell + read surfaces)

Playwright-style manual QA against the Vercel preview. No backend tests
(T-0118a changes no backend). Run every section at viewports 375 / 768 /
1280 unless noted.

## 1. Auth gate + redirect (AC-1, AC-2)

- [ ] Unauthenticated GET `/dashboard/admin` → redirected to `/admin/login?redirect=/dashboard/admin` (admin branch, NOT customer `/login`).
- [ ] Unauthenticated GET `/dashboard/admin/orders` (and `/faktury`, `/audit`) → same admin-login redirect, `redirect` param is path-only.
- [ ] Regression: unauthenticated `/dashboard/zakaznik/*` → `/login`; `/dashboard/maker/*` → `/login` (customer/maker branches unchanged).
- [ ] No redirect loop: `/admin/login` itself renders unauthenticated (it is outside the gated subtree).
- [ ] Correct admin credentials on `/admin/login` → `login('admin', …)` issues the `aud=admin` cookie, `router.push` lands on the guarded `redirect` target.
- [ ] Non-admin credentials → keyed `auth.forbidden` message; no admin session created.
- [ ] The login form has NO register / magic-link / OAuth affordance.

## 2. Shell (AC-3)

- [ ] Authenticated admin: shell header shows brand + identity + logout; nav has Přehled / Objednávky / Faktury / Audit log.
- [ ] Active section carries `aria-current="page"` and highlight.
- [ ] Forward-compat sections (Výplaty / Fronta událostí / Makeři / Uživatelé / Nastavení zemí) render as visibly-pending non-links (mobile menu) — NO live link to a not-yet-built route (no 404 on click; they are not clickable).
- [ ] Logout → POST `/auth/logout`, routes to `/admin/login`.
- [ ] Mobile (375): hamburger toggles the nav; all entries reachable.

## 3. Overview (AC-4)

- [ ] KPI tiles: Paid / Accepted / Shipped / Disputed counts render (from the all-orders read `pageSize:1` probes); each tile links to `/dashboard/admin/orders?state=…`.
- [ ] Disputed tile emphasises (red) when count > 0.
- [ ] Pending-payout + stalled-outbox tiles render "—" + pending note, link to the forward-compat surface; info banner explains the count gap.
- [ ] A failing count read renders "—" (no crash).

## 4. All-orders list (AC-5, AC-6, AC-9, AC-10, AC-11)

- [ ] Columns: order number, createdAt (Czech short), state badge, makerName, customerEmail, countryCode, total (`formatCzk`). Sorted CreatedAt DESC.
- [ ] Admin sees `customerEmail` (operator surface — intentional).
- [ ] Each row links forward to `/dashboard/admin/orders/{orderId}` (slice b — may 404 until b ships; not a live dead nav link).
- [ ] Filters (state / country / maker / customerEmail / date) via server `<form method="get">`; submit writes searchParams, resets to page 1.
- [ ] `?state=Paid&country=CZ&page=2` round-trips on back/forward + deep link.
- [ ] Junk params (`page=0`, `page=abc`, unknown `state`) clamp/drop to defaults, no error page. `page=1` absent from canonical pagination URLs.
- [ ] Empty state (keyed), error state (`Alert` + retry), loading skeleton.
