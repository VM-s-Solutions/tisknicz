# T-0116 — Manual QA plan (maker payout dashboard)

Playwright-style manual QA against the Vercel preview. No backend tests
(no backend change in T-0116). Tykání copy throughout.

## List — `/dashboard/maker/vyplaty`

- [ ] Logged-in maker with batches: rows render with batch number, total paid
      (`formatCzk`), order count, state badge, date — DESC by date (most-recent
      first), server-sorted.
- [ ] State badges show exactly two values: `Připravujeme` (Processing,
      warning) and `Vyplaceno` (Completed, success). No `Pending` ever.
- [ ] `?page=2` → second page; pagination prev/next round-trip; `page=1` absent
      from canonical URL.
- [ ] Junk params (`page=0`, `page=abc`) clamp to page 1, no error page.
- [ ] Zero batches → informational empty state (`Zatím nemáš žádné výplaty`),
      not an error, not blank.
- [ ] List API 5xx/network → `Alert variant="error"` with title/body + retry
      link, no blank page / thrown render error.

## Detail — `/dashboard/maker/vyplaty/{batchId}`

- [ ] Batch summary block: number, total, order count, state badge, date.
- [ ] Per-order breakdown table: order number, product price, shipping,
      platform fee, net payout — all via `formatCzk`, figures verbatim from the
      backend (no client arithmetic).
- [ ] Reconciliation eyeball: product − fee + shipping == net payout per row;
      Σ net payout == summary total.
- [ ] Foreign / unknown `batchId` → Next.js `notFound()` page (one shape).
- [ ] `feeInvoiceId` set → `Stáhnout fakturu` button downloads
      `faktura-{batchNumber}.pdf` (blob helper, not a generated file method).
- [ ] Download failure → inline i18n alert, button re-enables.
- [ ] `feeInvoiceId` null → button absent (no disabled stub).

## Cross-cutting

- [ ] CSV absence: grep the route + helper for `csv` → zero hits; no CSV link
      / affordance / call anywhere (AC-10).
- [ ] Responsive at 375 / 768 / 1280: cards `< md`, grid table `≥ md`, no
      horizontal scroll at 375, tap targets reachable.
- [ ] Hygiene: zero `any`, zero `console.*`, zero hardcoded Czech outside
      `cs-CZ.ts`; `npm run lint` + `npm run build` clean; `node
      scripts/check-consistency.mjs` exit 0.
