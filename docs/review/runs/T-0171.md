  gates (product CTA + `/objednavka`) widened together; the existing test was updated to the new
  prop rather than deleted.
- **PUB-M5 degrades safely:** the landing page falls back to the launch six if the category read
  fails — a landing page must never hard-fail on reference data.
- **Rules:** no `any`, i18n in one `// T-0171` block, existing primitives reused (`RefreshButton`
  and `ScrollToTop` both already existed — no new mechanism), semantic tokens.
- **Verified beyond unit tests:** the stale-category path was exercised against the running app,
  since that one is a server-render branch a unit test would only approximate.
